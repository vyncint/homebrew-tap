# vyncint/homebrew-tap

Homebrew tap for [vyncint](https://github.com/vyncint)'s tools.

## Available

### openshell-driver-applecontainer

An [OpenShell](https://github.com/NVIDIA/OpenShell) compute driver that runs each sandbox in
its own [apple/container](https://github.com/apple/container) micro-VM on Apple silicon.

```sh
brew install vyncint/tap/openshell-driver-applecontainer
```

The cask installs the binary only. Finish the setup — and install the prerequisites it needs —
as described in
[the driver's README](https://github.com/vyncint/openshell-driver-applecontainer#readme).

## Contents

Casks in this tap are generated by [GoReleaser](https://goreleaser.com) from each tool's release
workflow. Edit them there, not here.
