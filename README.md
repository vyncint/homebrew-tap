# vyncint/homebrew-tap

Homebrew tap for [vyncint](https://github.com/vyncint)'s tools.

## Available

### mossaic

GitHub's contribution chart in your terminal, and a planner for
[contribution art](https://github.com/vyncint/mossaic#pixel-art-across-the-year) —
draw a picture across a whole year and track what each day owes.

```sh
brew install vyncint/tap/mossaic
```

Installs three binaries — `mossaic`, `mossaic-art` and `mossaic-glyphs` — plus a copy of the
built-in art templates under `share/mossaic/templates` to start your own from. Static builds:
macOS and Linux, Intel and arm64, no Rust toolchain needed.

### openshell-driver-applecontainer

An [OpenShell](https://github.com/NVIDIA/OpenShell) compute driver that runs each sandbox in
its own [apple/container](https://github.com/apple/container) micro-VM on Apple silicon.

```sh
brew install vyncint/tap/openshell-driver-applecontainer
```

The cask installs the binary only. Finish the setup — and install the prerequisites it needs —
as described in
[the driver's README](https://github.com/vyncint/openshell-driver-applecontainer#readme).

## Contents

Everything here is **generated by the release workflow of the tool it installs** — the casks by
[GoReleaser](https://goreleaser.com), and `Formula/mossaic.rb` by
[mossaic's own `binaries.yml`](https://github.com/vyncint/mossaic/blob/main/.github/workflows/binaries.yml).
Edit them there, not here: a hand-edit is overwritten by the next release, silently.
